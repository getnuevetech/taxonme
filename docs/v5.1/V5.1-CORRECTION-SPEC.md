# V5.1 Development Correction Specification (TaxOnMe)

**Status:** Phase 0 — **FROZEN** (Wave 6, 2026-08-31)  
**Golden fixtures:** [`golden-cp2000-transcript.json`](./golden-cp2000-transcript.json), [`golden-levy-lt11.json`](./golden-levy-lt11.json)  
**Imm analogue:** ImmigrationOnMe `V5.1-CORRECTION-SPEC.md` — **contracts only**, no USCIS/VAWA content.

## Purpose

When Pipeline B (agency matter analysis) runs, TaxOnMe must feed customer presentation from a **correct, stale-proof, deduplicated, isolated, gated, and operationally reliable** pipeline — not from ad-hoc model text.

## Delivery sequence (locked)

```
0  Correction Spec + golden tax JSON     ← this document
F  Orchestration reliability
A  Document classification + dedupe
B  Fact ledger + provenance + invalidation
C  Retrieval / Presentation / Recommendation locks
E  Approval gate (BLOCK / WARNING) + audit trail
D  Unknown / conflict-driven next actions
G  Multi-fixture pack (positive + negative)
```

## Tax defects this program corrects

| # | Defect | Phase |
| --- | --- | --- |
| 1 | Notice/transcript misclassified as generic “other” from `docKind` | A |
| 2 | Balance stays “you told us” despite transcript | B |
| 3 | Collections copy recommends new 1040 / exam workbook | C |
| 4 | Duplicate evidence rows in customer view | A |
| 5 | Generic “review return / ask follow-up” outranks gap resolvers | D |
| 6 | “Options review / processing not needed” while docs exist | A/E |
| 7 | Analysis storms (retries / concurrent runs) | F |
| 8 | Soft approve with no fail-closed BLOCK | E |
